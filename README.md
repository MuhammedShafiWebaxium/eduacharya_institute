# EduAcharya Institute

Server-rendered marketing site built with TanStack Start, TanStack Router, React, and Vite.

## Commands

- `npm run dev` — start the local development server
- `npm run build` — create the production client and SSR bundles
- `npm run start` — preview the production build
- `npm run typecheck` — validate TypeScript
- `npm run lint` — run ESLint

Routes live in `src/routes`. Global styles live in `src/styles.css`.
